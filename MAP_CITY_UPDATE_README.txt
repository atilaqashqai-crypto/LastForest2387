MAP EXPANSION + CITY UPDATE

- The playable terrain was expanded from roughly 300m x 300m to 600m x 600m.
- Terrain resolution was kept close to the original by using 6m cells instead of 3m cells.
- The outer mountain/wall boundary was moved outward to the new map edge.
- Forest, props, loot and zombie spawn bounds were expanded to use the new world.
- A procedural low-poly city was added in the eastern half of the new area (roughly x=100..250, z=-105..105).
- The city includes roads, sidewalks/road markings, 20 buildings, hospital, police building, streetlights, static cars, containers/rubble and an entrance sign.
- The city is intentionally primitive/asset-free so it works with the existing project without importing external models.
- The existing cabin, bunker, vehicles, building system, multiplayer and UI were left in place.

Godot 4.7 was not available in this environment for runtime playtesting. Open the project in Godot and test the map after extraction.
